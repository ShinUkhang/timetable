# 🏫 배화여자고등학교 스마트 시간표 웹앱 (모바일 최적화)

스마트폰에서 한 손으로 편리하게 조회할 수 있도록 제작된 **배화여자고등학교 모바일 전용 일과 시간표 및 교무 지원 웹 애플리케이션**입니다.

GitHub Pages를 통해 별도의 서버 비용 없이 무료로 링크를 배포할 수 있습니다.

---

## 📱 주요 기능 소개

### 1. 👤 내 시간표 원클릭 조회
- **기본 교사 저장 (자동 기억)**: '⭐ 기본으로 저장'을 누르면 스마트폰 브라우저가 선생님 성함을 기억하여, 다음 접속 시 자동으로 내 시간표가 바로 열립니다.
- **오늘 요일 자동 강조**: 오늘 요일(월~금) 열이 시각적으로 하이라이트되어 현재 시간표를 빠르게 확인할 수 있습니다.
- **수업 교환 & 보강 추천 바텀시트**:
  - 파란색 수업을 터치하면 바닥에서 추천 모달이 열립니다.
  - 🤝 **상호 맞교환**: 나와 상대방이 서로 비어 있는 최적의 교체 조합 추천 (같은 반/같은 요일 우선)
  - 🙋 **보강/대강 가능 교사**: 해당 시간 공강인 선생님 목록 (당일 시수 적은 순서 정렬)

### 2. 🏫 반별(교실) 시간표 조회
- 1-1반부터 3-7반까지 학급별 주간 시간표 확인
- 교시별 과목명 및 담당 선생님 성함 표시

### 3. 🍱 오늘의 급식 & 점심 짝꿍
- **NEIS 실시간 연동**: 오늘 날짜의 배화여고 중식 식단을 실시간으로 불러옵니다.
- **점심 짝꿍 찾기 (4, 5교시)**:
  - 🟢 4, 5교시 연속 공강 (여유 있는 식사)
  - 🔵 4교시만 공강 (일찍 식사 가능)
  - 🟡 5교시만 공강 (늦게까지 식사 가능)
  - 🔴 4, 5교시 모두 수업 (제시간 식사)

### 4. 📞 교직원 전화번호 및 교실 위치 검색
- 교사/행정실/특별실 이름, 부서, 위치 실시간 검색
- 학년부/연구교무/행정실/특별실 빠른 필터 칩
- **원터치 통화 (`tel:`)** 및 **내선번호 복사 (`📋`)** 기능
- 담임 교사의 경우 개인 좌석 위치와 함께 **교실 내선번호 및 학급 위치** 표시

### 5. 👥 공통 공강 계산 & 전체 교사 퀵 뷰어
- 여러 선생님을 선택하여 그룹 전원이 함께 비는 공통 공강 시간표 자동 도출
- 43명 교사 시간표 빠른 검색 및 이동

## 🚀 깃허브(GitHub Pages) 배포 방법 (3분 완성)

### 1단계: GitHub에서 새 저장소(Repository) 만들기
1. [GitHub](https://github.com/)에 로그인합니다.
2. 우측 상단 `+` 버튼 ➡️ **[New repository]** 클릭.
3. **Repository name** 입력: 예) `timetable` 또는 `baehwa-timetable`
4. 공개 범위: **Public** 선택 (GitHub Pages 무료 배포를 위해 Public 필수).
5. 하단의 다른 체크박스(Add a README file 등)는 모두 비워두고 **[Create repository]** 클릭.

---

### 2단계: 터미널에서 코드 업로드하기
이 프로젝트 폴더(`c:\Users\user\Desktop\자동화프로그램\수업시간표`)에서 터미널(PowerShell 또는 CMD)을 열고 아래 명령어를 순서대로 실행합니다:

```bash
# 1. 깃 저장소 초기화 및 첫 커밋 (이미 완료되어 있을 수 있습니다)
git init
git add .
git commit -m "feat: 배화여고 모바일 스마트 시간표 웹앱"

# 2. 기본 브랜치를 main으로 지정
git branch -M main

# 3. 원격 저장소 주소 연결 (YOUR_USERNAME과 REPO_NAME을 본인의 깃허브 주소로 변경)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# 4. GitHub로 업로드 (최초 1회 로그인 창이 뜹니다)
git push -u origin main
```

---

### 3단계: GitHub Pages 무료 웹사이트 활성화
1. 방금 업로드한 GitHub 저장소 화면으로 이동합니다.
2. 상단 메뉴에서 **[Settings]** 탭을 클릭합니다.
3. 왼쪽 사이드바에서 **[Pages]** 메뉴를 클릭합니다.
4. **Build and deployment** 항목의 **Branch** 설정을:
   - `None` ➡️ **`main`** 으로 변경
   - 폴더는 **`/(root)`** 그대로 두고
   - 우측의 **[Save]** 버튼 클릭!
5. 약 1~2분 후 페이지 상단에 초록색 체크와 함께 **배포 링크**가 나타납니다:
   > 🌐 **https://YOUR_USERNAME.github.io/YOUR_REPO/**
