# 🏫 배화여자고등학교 스마트 시간표 & 등교·급식지도 웹앱 (모바일 최적화)

스마트폰에서 한 손으로 편리하게 조회할 수 있도록 제작된 **배화여자고등학교 모바일 전용 일과 시간표 및 등교·급식 지도 교무 지원 웹 애플리케이션**입니다.

GitHub Pages를 통해 별도의 서버 비용 없이 영구 무료로 배포·운영됩니다.

- 🌐 **공식 배포 웹사이트**: [https://shinukhang.github.io/timetable/](https://shinukhang.github.io/timetable/)

## 📱 주요 기능 소개

### 1. 🏫 오늘 & 날짜별 등교·급식 지도 교사 실시간 조회 (NEW!)
- **오늘의 당번 즉시 확인**: 앱 접속 시 오늘 날짜의 **등교지도(본관 07:30~08:00 / 별관 07:30~07:50)** 및 **중식지도(3층 / 4층 12:10~13:10)** 담당 선생님 성함이 눈에 띄게 표시됩니다.
- **내 당번 자동 알림**: 내 시간표에서 본인을 선택하면 당일 지도 당번 여부가 상단에 강조 배너로 자동 안내됩니다.
- **날짜 자유 이동**: `[◀ 이전]` `[오늘]` `[다음 ▶]` 및 `[📅 달력 선택]`으로 원하는 날짜의 지도 일정을 언제든지 확인 가능합니다.
- **📋 전체 명단 & 지도 수칙**: `[📋 전체]` 버튼을 누르면 한 달 치 지도 배정표와 등교/중식 지도 유의사항을 바텀시트로 볼 수 있습니다.
- **선생님 터치 연동**: 지도 선생님 이름을 누르면 해당 선생님의 시간표로 바로 이동합니다.

### 2. 👤 내 시간표 원클릭 조회
- **기본 교사 저장 (자동 기억)**: '⭐ 기본으로 저장'을 누르면 스마트폰 브라우저가 선생님 성함을 기억하여, 다음 접속 시 자동으로 내 시간표가 바로 열립니다.
- **교직원 이름 가나다순 정렬**: 43명 교사 명단이 가나다순으로 정돈되어 빠른 선택이 가능합니다.
- **오늘 요일 자동 강조**: 오늘 요일(월~금) 열이 시각적으로 하이라이트되어 현재 시간표를 빠르게 확인할 수 있습니다.
- **수업 교환 & 보강 추천 바텀시트**:
  - 파란색 수업을 터치하면 바닥에서 추천 모달이 열립니다.
  - 1순위: 🙋 **보강/공강 교사**: 해당 시간 공강인 선생님 목록 (당일 시수 적은 순서)
  - 2순위: 🤝 **상호 맞교환**: 나와 상대방이 서로 비어 있는 최적의 교체 조합 추천

### 3. 🏫 반별(교실) 시간표 조회
- 1-1반부터 3-7반까지 학급별 주간 시간표 확인
- 교시별 과목명 및 담당 선생님 성함 표시

### 4. 🍱 오늘의 급식 & 점심 짝꿍 & 중식지도
- **NEIS 실시간 연동**: 오늘 날짜의 배화여고 중식 식단을 실시간으로 불러옵니다.
- **오늘 중식 지도 교사**: 3층/4층 담당 교사가 급식 메뉴 바로 아래 함께 표시됩니다.
- **점심 짝꿍 찾기 (4, 5교시)**:
  - 🟢 4, 5교시 연속 공강 (여유 있는 식사)
  - 🔵 4교시만 공강 (일찍 식사 가능)
  - 🟡 5교시만 공강 (늦게까지 식사 가능)
  - 🔴 4, 5교시 모두 수업 (제시간 식사)

### 5. 📞 교직원 전화번호 및 교실 위치 검색
- 교사/행정실/특별실 이름, 부서, 위치 실시간 검색 (가나다순 정렬)
- **원터치 통화 (`tel:`)**: 스마트폰에서 터치 시 `02-724-0***`로 바로 다이얼 연결
- **내선번호 복사 (`📋`)** 기능 지원
- 담임 교사의 경우 개인 좌석 위치와 함께 **교실 내선번호 및 학급 위치** 표시

### 6. 👥 공통 공강 계산 & 전체 교사 퀵 뷰어
- 여러 선생님을 선택하여 그룹 전원이 함께 비는 공통 공강 시간표 자동 도출

## 📂 등교·급식지도 엑셀 파일 추가 & 자동 업데이트 방법

앞으로 매월(10월, 11월 등) 새로운 등교/급식지도 파일이 나오면 이렇게만 하시면 됩니다:

1. **`등교급식지도` 폴더에 엑셀 파일(`.xlsx`) 넣기**
   - 예: `등교급식지도\등교지도, 중식지도 (10월).xlsx`
2. **`github_upload.bat` 더블클릭 실행!**
   - 엑셀 파일을 자동으로 읽어 `index.html`을 최신화하고,
   - GitHub에 자동 커밋 & 푸시하여 웹사이트에 실시간 반영됩니다.
   *(로컬에서만 먼저 확인하고 싶다면 `등교급식지도_반영.bat`을 실행하세요)*

## 📁 프로젝트 파일 구성

- `index.html`: 메인 모바일 웹 애플리케이션 (PWA 지원)
- `update_duty.js`: 등교·급식지도 엑셀 자동 분석 및 동기화 스크립트
- `등교급식지도/`: 월별 등교지도, 중식지도 엑셀 파일 저장 폴더
- `github_upload.bat`: 엑셀 동기화 + GitHub 원클릭 배포 배치 파일
- `등교급식지도_반영.bat`: 로컬 엑셀 동기화 및 즉시 확인 배치 파일
- `cat.png`, `icon-192.png`, `icon-512.png`, `favicon.png`: 노란 고양이 앱 아이콘 에셋
